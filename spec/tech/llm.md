# LLM

## Назначение

Формирует человекочитаемый ответ на основе команд, найденных поиском (`rag/`, top-3).

## Режимы

Задаются в `.env` (образец — `.env.example`; файл подхватывается через python-dotenv):
- `USE_STUB=true` (по умолчанию) — заглушка: ответ собирается из найденных команд без обращения к API;
- `USE_STUB=false` + `OPENAI_API_KEY` — вызов OpenAI (модель gpt-4o-mini, temperature 0,2).

## Промпт

Задаёт формат ответа:
1. Название
2. Команда
3. Описание
4. Примеры применения

Модели запрещено придумывать команды вне контекста.

## Защита от выдумок

Если поиск ничего не нашёл (ни одного терма запроса нет в корпусе, например «Как сварить борщ?»), LLM **не вызывается**:
возвращается «Подходящая команда не найдена. Попробуйте описать задачу другими словами.» (spec/product/answer_format.md).

## Fallback

Если API недоступен — возвращается заглушка с найденными командами и текстом ошибки.
