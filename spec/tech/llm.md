# LLM

## Назначение

Формирует человекочитаемый ответ на основе найденных команд.

## Режимы

- USE_STUB = True — заглушка (работает без API-ключа)
- USE_STUB = False — реальный вызов OpenAI

## Промпт

Задаёт формат ответа:
1. Название
2. Команда
3. Описание
4. Примеры применения

## Fallback

Если API недоступен — возвращается заглушка с найденными командами.
