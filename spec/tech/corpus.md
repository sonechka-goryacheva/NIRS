# Корпус

## Формат записи

    {
      "name": "Название",
      "command": "команда",
      "description": "описание",
      "examples": ["пример1", "пример2", "пример3"],
      "tags": ["тег1", "тег2", "тег3", "tag4", "tag5"],
      "platform": "unix | mac | linux | windows | cross"
    }

- examples — ровно 3, tags — не меньше 5 (на русском и английском).
- Теги — главный источник слов для поиска: описания короткие (2–7 слов), поэтому в тегах — действие, объект и частые
  синонимы на обоих языках («удалить», «remove», «delete», «папка», «файл»). Без тегов MRR падает с 0,78 до 0,52 (rag/REPORT.md).
- Корпус индексируется модулем `rag/`; после изменения id команд обновить тестовый набор `rag/queries.json`.
- `id` и `category` в файле не хранятся: сервер добавляет их при загрузке (`<имя файла>-<индекс>`, например `git-3`).

## Категории

- linux.json
- mac.json
- git.json
- docker.json
- sql.json
- python.json
- network.json
- powershell.json
