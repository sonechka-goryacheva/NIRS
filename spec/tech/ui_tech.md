# UI (технически)

## Текущая версия

Консольный интерфейс в app/ui.py.

## Поведение

- Печатает баннер.
- Читает запрос из stdin.
- Вызывает search() и ask_llm().
- Печатает ответ.
- Выход по exit / quit / q / Ctrl+D.

## Планы

Замена на GUI (Tkinter / CustomTkinter) без изменения модулей search и llm.
