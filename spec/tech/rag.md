# RAG

## Подход

1. Загрузить корпус команд из data/corpus/.
2. Построить индекс BM25 по полям name + command + description + tags.
3. На запрос — токенизация и ранжирование.
4. Top-3 документа передаются в LLM как контекст.

## Токенизация

Нижний регистр, удаление пунктуации, разбиение по пробелам.
