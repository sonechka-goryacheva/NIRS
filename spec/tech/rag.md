# RAG (поиск)

Реализация — папка `rag/` (описание и запуск — `rag/README.md`, обоснование и результаты — `rag/REPORT.md`).
Требования — «Методические указания к НИРС (ОАД)»: поисковый индекс BM25 реализуется самостоятельно,
готовые поисковые индексы (rank-bm25, Elasticsearch, Whoosh…) не используются.

## Подход

1. Корпус — `data/corpus/*.json`; документ = одна команда, id = `<категория>-<индекс>` (spec/tech/corpus.md).
2. Индексируются поля `name + command + description + tags` (вес 1, `examples` не индексируются).
3. Предобработка (одинаковая для документов и запросов): нижний регистр, «ё» → «е», токены `[a-zа-я0-9]+`,
   лемматизация русских слов pymorphy3 (латиница — без изменений), удаление стоп-слов.
4. Обратный индекс `терм → {документ: TF}` и длины документов; ранжирование BM25 с IDF = ln(1 + (N − DF + 0,5)/(DF + 0,5)),
   k1 = 1,2, b = 0,75; сортировка по убыванию балла, при равных баллах — по ID (естественный порядок: категория, номер).
   Индекс пересобирается сам, когда меняются файлы `data/corpus/` (`app.search.get_engine()`).
5. Top-3 документа передаются в LLM как контекст (spec/tech/llm.md).
6. Тип ответа для чата (spec/tech/api.md, «Правила ответа»):
   - ни один терм запроса не встречается в корпусе → `not_found` без команд;
   - лучший документ содержит ≥ 50 % термов запроса и BM25 ≥ 5,0 → `found` (лучшая + до 2 похожих);
   - иначе → `not_found` с 1–3 командами.
   Пороги выбраны на тестовом наборе (rag/REPORT.md, раздел 6).

## Демонстрация без сервера

    python rag/demo.py ["вопрос"]

Три этапа в терминале: Retrieval (top-3 BM25 с ID и баллом) → Augmented (промпт `app/llm.py` с найденными командами) →
Generation (`app.llm.ask_llm`: заглушка или OpenAI по `.env`) + источники (ID, файл корпуса, номер записи).
Если поиск пуст — LLM не вызывается, ответ «Подходящая команда не найдена…».

## Интерфейс для приложения

    from app.search import search, Searcher      # обёртка над rag
    search(query, top_k=3, platform=None) -> list[Command]
    Searcher(corpus).answer(query) -> {"type": "found"|"similar"|"nothing", "commands": [...]}

После изменения файлов корпуса индекс пересобирается автоматически при следующем запросе; `app.search.reload()` — вручную.

## Качество

Оценка — spec/tech/benchmark.md. Текущие значения на 46 запросах: Recall@3 0,447, MRR 0,777, MRR@3 0,757, Recall@5 0,555.
