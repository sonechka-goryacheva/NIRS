# RAG

## Подход

1. Загрузить корпус команд из data/corpus/.
2. Построить индекс BM25 по полям name + command + description + tags.
3. На запрос — токенизация и ранжирование.
4. Top-3 документа передаются в LLM как контекст.
5. По оценкам BM25 выбирается тип ответа: уверенное совпадение → `found`; только отдалённые совпадения слов → `not_found` с 1–3 командами;
   совпадений нет → `not_found` без команд (spec/tech/api.md, «Правила ответа»). Пороги подбираются на бенчмарке.

## Токенизация

Нижний регистр, удаление пунктуации, разбиение по пробелам.
