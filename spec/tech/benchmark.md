# Бенчмарк

## Назначение

Проверка качества поиска на наборе кейсов.

## Файлы

- benchmark/cases.json — пары «запрос → ожидаемая команда»
- benchmark/run.py — прогон и метрика

## Метрика

Top-3 accuracy: доля запросов, для которых ожидаемая команда попала в топ-3.

## Запуск

    python benchmark/run.py
