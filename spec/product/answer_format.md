# Формат ответа нейросети

Ответ строится только из полей датасета: name, command, description, examples (+ category, platform для меток).
Типы ответа в API — spec/tech/api.md (`Reply`), тексты — errors.md.

## Найдено (`found`)
Лучшая команда целиком:
1. Название
2. Команда: `chmod +x script.sh`
3. Описание: делает файл исполняемым…
4. Примеры применения (ровно 3):
   - `chmod +x deploy.sh`
   - `chmod +x backup.sh`
   - `chmod -R +x scripts/`

Ниже — «Похожие:» до 2 команд; по нажатию раскрываются в такую же карточку.

## Не найдено, есть похожие (`not_found` + команды)
Сообщение:
> «Подходящая команда не найдена. Возможно, подойдут указанные ниже варианты?»

Далее — от 1 до 3 команд, у которых совпали значимые слова запроса; каждая в формате «Найдено».

## Ничего не найдено (`not_found` без команд)
Запрос не про IT или бессмыслица (например, «кракозябра»). Только сообщение:
> «Подходящая команда не найдена. Попробуйте описать задачу другими словами.»

Случайные команды не показываются.
