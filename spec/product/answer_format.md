# Формат ответа нейросети

## Обычный ответ

1. Название
2. Команда: chmod +x script.sh
3. Описание: делает файл исполняемым...
4. Примеры применения:
   - chmod +x deploy.sh
   - chmod +x backup.sh
   - chmod -R +x scripts/

## Ответ при ошибке

Сообщение:
> «Подходящая команда не найдена. Возможно, подойдут указанные ниже варианты?»

Далее — 3 команды, каждая в формате обычного ответа.

## Источник данных
Поля берутся из датасета: name, command, description, examples.
