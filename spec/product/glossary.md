# Глоссарий

## Датасет (корпус)
Набор команд, по которому ищет справочник. Хранится в `data/corpus/*.json`, редактируется администраторами.

## Категория
Группа команд, один файл корпуса. Ключ → подпись в интерфейсе:
linux → Linux, mac → macOS, git → Git, docker → Docker, sql → SQL, python → Python, network → Сеть, powershell → PowerShell.

## Команда (запись датасета)
Объект с полями: id, category, name, command, description, examples (ровно 3), tags (не меньше 5), platform.

## Платформа
ОС, где работает команда: linux, mac, windows, unix, cross (везде).

## Чат
Переписка пользователя со справочником: запросы и ответы. Принадлежит одному пользователю, видна только ему.

## Ответ
Лучшая найденная команда целиком и до 2 похожих; либо «не найдено» и 1–3 команды с совпавшими словами; либо только «не найдено», если совпадений нет (answer_format.md).

## Пользователь (роль user)
IT-специалист, который ищет команды.

## Администратор (роль admin)
Пользователь, который дополнительно ведёт датасет и учётные записи. Права — в roles.md.

## Гость
Тот, кто ещё не вошёл.
