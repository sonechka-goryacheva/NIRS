# Глоссарий

## Датасет
Набор команд, загруженных администраторами.
Хранится в файлах data/corpus/*.json.

## Категория
Тематическая группа команд: Linux, Mac, Git, Docker, SQL, Python, Network, PowerShell.

## Запись команды
Один объект в датасете с полями:
name, command, description, examples, tags, platform.

## Платформа
ОС, для которой работает команда: linux, mac, windows, unix, cross.

## Пользователь
IT-специалист, использующий справочник.

## Администратор
Пользователь с расширенными правами: редактирует датасет и видит и редактирует учётные записи.
