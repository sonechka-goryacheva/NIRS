# Глоссарий

## Датасет (корпус)
Набор команд, по которому ищет справочник. Хранится в `data/corpus/*.json`, редактируется администраторами.

## Категория
Группа команд, один файл корпуса. Ключ → подпись в интерфейсе:
linux → Linux, mac → macOS, git → Git, docker → Docker, sql → SQL, python → Python, network → Сеть, powershell → PowerShell.

## Команда (запись датасета)
Объект с полями: id, category, name, command, description, examples (ровно 3), tags (не меньше 5), platform.

## Платформа
ОС, где работает команда: linux, mac, windows, unix, cross (везде).

## Чат
Переписка пользователя со справочником: запросы и ответы. Принадлежит одному пользователю, видна только ему.

## Ответ
Лучшая найденная команда целиком и до 2 похожих; либо «не найдено» и 1–3 команды с совпавшими словами; либо только «не найдено», если совпадений нет (answer_format.md).

## Пользователь (роль user)
IT-специалист, который ищет команды.

## Администратор (роль admin)
Пользователь, который дополнительно ведёт датасет и учётные записи. Права — в roles.md.

## Гость (роль guest)
Пользователь в гостевом режиме: вошёл кнопкой «Продолжить без регистрации». Может спрашивать, смотреть историю и датасет;
его чаты удаляются при выходе. Тот, кто ещё никак не вошёл, — «без входа».

## Свой датасет («Мои команды»)
Команды, которые пользователь загрузил из своего файла JSON или CSV. Видны только ему, участвуют в поиске только в его чатах.
Категория `my`, правила мягче общего датасета: примеров до 3, теги необязательны.

## Код восстановления
Одноразовый код `XXXX-XXXX-XXXX`, выдаётся при регистрации. Позволяет задать новый пароль без старого («Забыли пароль?»);
после использования сгорает, взамен выдаётся новый.

## Тема оформления
Светлая или тёмная; по умолчанию — как в системе. Хранится в браузере.

## Обучение
Тесты по темам (категориям справочника и своим командам) с вариантами ответа. Ошибки копятся в «Повторить ошибки»
и уходят оттуда после верного ответа — так материал закрепляется. Результат темы — лучший % за полный тест.
