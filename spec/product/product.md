# Справочник IT-команд

## Пользователь
IT-специалист, который:
- столкнулся с задачей и не знает, какую команду применить;
- хочет узнать значение или применение команды.

Администратор — отдельная роль (см. roles.md).

## Задача
Быстро получить нужную команду или объяснение существующей
с помощью нейросети, которая ищет по датасету команд.

## Основной сценарий
1. Пользователь пишет запрос-описание проблемы в чат с нейросетью.
2. Нейросеть анализирует текст и ищет команды в датасете.
3. Пользователь получает: название команды, команду, краткое описание, 3 примера применения.

## Дополнительные сценарии
- Просмотр общего списка команд с классификацией по категориям.
- Уточняющие вопросы к нейросети.
- История чатов.
- Администратор редактирует датасет и видит список пользователей и их учетки.

## Что входит
- Роли: пользователь, администратор.
- Авторизация, регистрация, смена пароля.
- Чат с нейросетью.
- Поиск по датасету (BM25 + LLM).
- Боковая панель со списком команд по категориям.

## Что не входит
- Запуск команд из приложения.
- Работа с реальными серверами пользователя.
- Сбор команд из интернета в реальном времени.
- Восстановление пароля.
