# Роли и права

Роли: **guest** (гостевой режим без регистрации), **user** (пользователь, IT-специалист) и **admin** (администратор).
Без входа доступны только вход, регистрация, «Забыли пароль?» и кнопка «Продолжить без регистрации».

## Матрица прав

| Действие | Без входа | guest | user | admin |
|---|:-:|:-:|:-:|:-:|
| Регистрация (создаётся только роль user) | ✓ | ✓ | — | — |
| Вход по логину и паролю | ✓ | ✓ | ✓ | ✓ |
| Гостевой вход без регистрации | ✓ | — | — | — |
| «Забыли пароль?»: новый пароль по логину и коду восстановления | ✓ | ✓ | ✓ | ✓ |
| Выход | — | ✓ | ✓ | ✓ |
| Профиль: логин, роль, дата регистрации, тема оформления | — | ✓ | ✓ | ✓ |
| Смена пароля из профиля (без старого пароля), новый код восстановления | — | — | ✓ | ✓ |
| Чат: новый запрос, уточняющие вопросы | — | ✓ | ✓ | ✓ |
| История **своих** чатов: просмотр, поиск, переименование, удаление | — | ✓ | ✓ | ✓ |
| Справочник команд: просмотр категорий, списков, карточек | — | ✓ | ✓ | ✓ |
| Обучение: тесты по темам, повтор ошибок, свой прогресс | — | ✓ | ✓ | ✓ |
| Свой датасет («Мои команды»): загрузить файл, изменить, удалить | — | — | ✓ | ✓ |
| Общий датасет: добавить, изменить, удалить команду | — | — | — | ✓ |
| Пользователи: список с поиском и фильтром по роли | — | — | — | ✓ |
| Пользователи: создать с ролью user или admin | — | — | — | ✓ |
| Пользователи: изменить роль, задать новый пароль | — | — | — | ✓ |
| Пользователи: удалить (вместе с историей чатов и своим датасетом) | — | — | — | ✓ |

## Правила
1. Регистрация всегда создаёт роль user. Роль из запроса игнорируется.
2. Первого администратора создают вручную: `python -m app.auth admin <логин>`. Дальше администраторы назначаются в интерфейсе.
3. Администратор не может удалить себя и изменить свою роль.
4. В системе всегда остаётся хотя бы один администратор: последнего нельзя понизить или удалить.
5. Администратор **не видит** содержимое чатов, личные команды и прогресс обучения других пользователей —
   только количество чатов и своих команд (в окне «Изменить»).
6. Чужой чат и чужая личная команда для пользователя «не существуют»: сервер отвечает 404, а не 403.
7. Права проверяет сервер на каждом запросе. Скрытие кнопок в интерфейсе — только удобство, не защита.
8. Смена роли или удаление действуют сразу: при следующем запросе пользователь получит новые права или 401.

## Гостевой режим
1. «Продолжить без регистрации» создаёт временную учётную запись `guest-xxxxxx` с ролью guest и сессию до закрытия браузера.
2. Чаты и прогресс обучения гостя живут до выхода: при выходе, входе в аккаунт или регистрации они удаляются; брошенные гостевые сессии
   сервер удаляет через 24 часа бездействия. В новый аккаунт чаты гостя **не переносятся** (об этом предупреждаем на регистрации).
3. Гостю закрыты: свой датасет, смена пароля и код восстановления, администрирование (сервер отвечает 403).
4. Гости не показываются в «Пользователях» и не учитываются администратором.

## Восстановление пароля
1. При регистрации выдаётся одноразовый **код восстановления** (формат `XXXX-XXXX-XXXX`), показывается один раз.
2. «Забыли пароль?» на странице входа: логин + код + новый пароль. Использованный код сгорает, взамен выдаётся новый.
3. В профиле вошедший пользователь меняет пароль без старого и может выпустить новый код (старый перестаёт действовать).
4. Код потерян — новый пароль задаёт администратор (Пользователи → Изменить).

## Что сознательно не входит
- Восстановление пароля по почте (нет почты в данных).
- Блокировка без удаления, журнал действий администратора — можно добавить позже (см. CHANGE_HISTORY).
