# Роли

## Пользователь (IT-специалист)
- Чат с нейросетью.
- Просмотр датасета по категориям.
- Уточняющие вопросы.
- История чатов.
- Информация о профиле.
- Смена пароля.

## Администратор
Всё, что у пользователя, плюс:
- Редактирование датасета: добавление, изменение, удаление команд.
- Просмотр и изменение учётных записей зарегистрированных пользователей.

## Правила
- Обычный пользователь не может стать администратором.
- Администратор назначается только вручную.
