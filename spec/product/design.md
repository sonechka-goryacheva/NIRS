# Дизайн

Мятная палитра и полупрозрачные «стеклянные» плашки. Одна палитра — две темы:
**тёмная изумрудная** (вход, регистрация) и **светлая мятная** (всё после входа).
Источник правды — токены в `web/assets/css/theme.css`. В компонентах цвета не пишем — только `var(--…)`.

Прежний сине-фиолетовый вариант в проекте не хранится — только архивом `spravochnik-web-sine-fioletovyi.zip` (вне репозитория).

## Принципы
1. Читаемость важнее эффектов: текст всегда на плотной плашке, контраст основного текста не ниже 4.5:1.
2. Стекло — только для крупных контейнеров: карточка входа, боковая панель, карточки команд, окна, строка ввода.
3. Один акцент — мятный градиент `--accent-grad`: главная кнопка, отправка, сообщения пользователя, активный пункт.
4. Команды и примеры — моноширинным шрифтом в отдельном блоке с кнопкой «Скопировать».
5. На входе внимание на форме: кнопка «Войти» полупрозрачная, при наведении и нажатии — светлее (мятно-белое стекло), ссылки тонкие.
6. Анимации короткие (до 250 мс), отключаются при `prefers-reduced-motion`.

## Типографика
- Текст — **Inter** 400/500/600, базовый размер 1rem.
- Код — **JetBrains Mono** 400/500, 0.875–0.9375rem.
- Заголовки: вход — 2.75rem / 500, пустой чат — 2rem, окна — 1.375rem.
- Надзаголовки `.eyebrow` — 0.75–0.8125rem, капс, разрядка 0.12–0.18em.

## Размеры и масштаб
Все размеры — в `rem` (кроме линий 1px). Корневой размер растёт с шириной окна:
`html { font-size: clamp(16px, calc(9px + 0.5vw), 21px) }` — 16px на ноутбуке, ~19px на 2000px, 21px на 2560px.

- Радиусы 0.75 / 1 / 1.5rem (`--r-sm/md/lg`), карточка входа — 1.75rem.
- Поля и кнопки — 2.75–3rem в высоту, маленькие кнопки — 2.125rem.
- Лента чата — до 51rem, боковая панель — 18rem.
- Окно «Редактировать датасет» — до 86rem × 58rem: примеры в один ряд, кнопки сохранения закреплены внизу формы.
- Точки перелома: 900px (приложение), 960px (вход), 600px (короткая подсказка в строке ввода).

## Графика
- **Логотип** `logo.svg` — две наложенные скруглённые плашки (светло-мятная и изумрудная) со строками текста.
- **Иконка вкладки** — тот же знак, встроен прямо в `index.html` (data-URI), поэтому браузер не может показать старую из кэша;
  `web/favicon.ico` (16–64 px) — для браузеров, которые сами запрашивают `/favicon.ico`; `apple-touch-icon.png` — для телефона.
- **Иллюстрация входа** `auth-keys.svg` — изометрические мятные клавиши `>_`, `Ctrl`, `C`, `Tab`, слегка покачиваются.
  Заходит на правый край карточки, поля не перекрывает. На ширине < 960px скрыта.
- Вокруг — стеклянные плашки с командами (`git status`, `docker ps -a`, `du -sh *`).
- Лиц и чужих персонажей нет.

## Компоненты
- `theme.css`: `.glass`, `.btn` (`-primary/-ghost/-danger/-text`, `-sm`, `-block`), `.icon-btn`, `.field` + `.label/.input/.textarea/.select/.field-hint/.field-error`,
  `.alert-error/-ok/-warn`, `.chip` (`-accent`, `-mono`), `.code`, `.modal`, `.toast`.
- `app.css`: каркас, боковая панель, лента, `.cmd-card` (одна карточка для чата и датасета), строка ввода, окна (`.modal-wide/-tall/-admin`), `.tabs`, `.crumbs`, `.rows/.row`, `.table`, 404.
- `auth.css`: карточка входа, иллюстрация, плавающие команды.

## Адаптивность
≥ 900px — панель рядом с чатом; < 900px — панель выезжает поверх, формы в одну колонку, в таблице пользователей остаются логин
(роль под ним) и кнопки-иконки. Минимальная ширина — 360px, без горизонтальной прокрутки.
