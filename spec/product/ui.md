# Интерфейс

## Общая структура
Приложение из 2–3 страниц:
1. Авторизация / регистрация.
2. Чат с нейросетью.

## Страница 1. Авторизация / регистрация

### Элементы
- Логин.
- Пароль.
- Смена пароля (для зарегистрированных).
- Кнопка «Войти».
- Ссылка «Зарегистрироваться».

---

## Страница 2. Чат с нейросетью

Стиль — как у DeepSeek: боковая панель + строка ввода.

### Боковая панель
Открывается кнопкой в верхнем левом углу.
Содержит:
- Кнопку закрытия боковой панели.
- Кнопку «Новый чат».
- Историю чатов.
- Кнопку «Датасет команд»:
  - при нажатии — выбор категории;
  - после выбора — список команд;
  - при нажатии на команду — полное описание.
- Поле «Информация о пользователе» (данные из регистрации).
- Для админа: кнопка «Редактировать датасет».

### Область чата
- Лента сообщений (пользователь / нейросеть).
- Строка ввода запроса.
- Кнопка отправки.

### Состояния
- Пустой чат: подсказка «Введите запрос».
- Загрузка: «Ищу...».
- Ответ: название, команда, описание, 3 примера.
- Ошибка: «Подходящая команда не найдена. Возможно, подойдут указанные ниже варианты?» + 3 команды.
