# Интерфейс

Одна веб-страница с адресами вида `#/...` (spec/tech/ui_tech.md). Оформление — design.md, права — roles.md, тексты ошибок — errors.md.

## Вход `#/login` и регистрация `#/register`
Тёмная изумрудная тема, светлая стеклянная карточка слева, мятные клавиши справа. Кнопка «Войти» полупрозрачная (при наведении и нажатии — светлее), ссылки тонкие — внимание на полях.

- **Вход**: логин, пароль (кнопка «показать»), «Войти»; ссылки «Зарегистрироваться» и «Сменить пароль».
- **Регистрация**: логин (3–32 символа, без пробелов), пароль (от 6), повтор пароля, «Создать аккаунт»; ссылка «Войти».
  После регистрации пользователь сразу в чате с ролью user.
- **Смена пароля** (окно): логин, текущий пароль, новый пароль, повтор. Доступна без входа и из профиля (логин подставлен).

## Приложение (после входа)
Светлая мятная тема. Слева боковая панель, справа чат. Панель скрывается кнопкой; на телефоне выезжает поверх.

### Боковая панель
- Логотип (ссылка на новый чат) и кнопка скрытия панели.
- «Новый чат».
- «История» — свои чаты, новые сверху, активный подсвечен. У каждого — «Удалить» (с подтверждением).
- «Датасет команд».
- Только admin: блок «Администрирование» — «Редактировать датасет», «Пользователи».
- Внизу — аватар, логин, роль → профиль.

### Чат `#/chat`, `#/chat/:id`
- Шапка — название чата (первые 48 символов первого запроса).
- Пустой чат: логотип, «Какую команду ищем?», подсказка и 4 примера запросов (нажатие — отправка).
- Лента: запрос пользователя справа, ответ слева.
- Строка ввода: растёт до 12.5rem (≈ 8 строк), до 2000 символов; `Enter` — отправить, `Shift+Enter` — новая строка.
- После первого запроса чат получает адрес `#/chat/<id>` и появляется в истории.

Состояния ответа:
- **Ищу** — анимированные точки.
- **Найдено** — карточка: название, категория, платформа, команда, описание, 3 примера; ниже «Похожие:» до 2 команд (раскрываются по нажатию).
- **Не найдено, есть похожие** — жёлтая плашка «…Возможно, подойдут указанные ниже варианты?» и 1–3 полные карточки.
- **Ничего не найдено** (бессмыслица) — только жёлтая плашка «…Попробуйте описать задачу другими словами.», без карточек.
- **Ошибка** — красная плашка с текстом ошибки.

У команды и каждого примера — «Скопировать» (уведомление «Скопировано»).

## Окна поверх чата
Закрываются крестиком, `Esc` и кликом по фону — возвращают к последнему чату. У каждого свой адрес.

### Датасет `#/dataset`
Крошки: Датасет команд › Категория › Команда.
1. 8 плиток категорий с числом команд.
2. Список категории: фильтр по названию, команде, тегу; строка — название, команда, платформа.
3. Карточка команды + теги.

### Профиль `#/profile`
Логин, роль, дата регистрации. «Выйти», «Сменить пароль».

### Администрирование (только admin)
Вкладки-ссылки «Команды» `#/admin/commands` и «Пользователи» `#/admin/users`.

**Команды.** Слева: категория (с числом команд), «Новая команда», фильтр, список. Справа — форма:
название, команда, категория, платформа, описание, 3 примера, теги (через запятую, ≥ 5).
«Добавить команду» / «Сохранить», у существующей — «Удалить» с подтверждением. Счётчики категорий обновляются сразу.

**Пользователи.** Поиск по логину, фильтр «Все роли / Пользователь / Администратор», «Создать».
Таблица: логин (у себя — метка «вы»), роль, дата регистрации, последний вход, число чатов, действия:
- «Изменить» — окно: роль, новый пароль (пусто — не менять). Свою роль менять нельзя (поле неактивно).
- «Удалить» — подтверждение с числом чатов, которые удалятся. У себя кнопка неактивна.
- «Создать» — окно: логин, роль, пароль.
Под таблицей подсказка о правилах (себя нельзя, последний admin остаётся).

## 404
Неизвестный адрес — карточка «Страница не найдена» и кнопка к чату (или ко входу).
