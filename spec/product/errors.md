# Сообщения об ошибках

Текст — то, что видит пользователь. Сервер отдаёт его в `detail`, а имя поля — в `field` (spec/tech/api.md).
Ошибка с `field` показывается под полем, без — плашкой над формой или уведомлением внизу экрана.

## Вход, регистрация, пароль

| Ситуация | Код | Поле | Текст |
|---|---|---|---|
| Пустой логин / пароль (проверка в браузере) | — | login / password | Введите логин / Введите пароль |
| Логин не 3–32 символа или с пробелом | 400 | login | Логин: от 3 до 32 символов, без пробелов |
| Пароль короче 6 символов | 400 | password | Пароль: минимум 6 символов |
| Повтор пароля не совпадает (браузер) | — | password2 | Пароли не совпадают |
| Логин занят | 409 | login | Пользователь с таким логином уже существует |
| Неверная пара логин/пароль | 401 | — | Неверный логин или пароль |
| Новый пароль совпадает с текущим | 400 | new_password | Новый пароль совпадает с текущим |
| Сессия истекла во время работы | 401 | — | Сессия истекла, войдите снова |

## Чат

| Ситуация | Код | Текст |
|---|---|---|
| Пустой запрос | 400 | Введите запрос |
| Запрос длиннее 2000 символов | 400 | Запрос слишком длинный: максимум 2000 символов |
| Чат удалён или чужой | 404 | Чат не найден |
| Нет уверенного совпадения, но есть похожие (ответ, не ошибка) | 200 | Подходящая команда не найдена. Возможно, подойдут указанные ниже варианты? + от 1 до 3 команд |
| Совпадений нет совсем — бессмыслица, не про IT (ответ, не ошибка) | 200 | Подходящая команда не найдена. Попробуйте описать задачу другими словами. — без команд |
| Сервер недоступен | — | Сервер недоступен. Проверьте подключение и попробуйте ещё раз |

## Администратор

| Ситуация | Код | Поле | Текст |
|---|---|---|---|
| Не admin открывает раздел | 403 | — | Недостаточно прав |
| Пустое название / команда / описание | 400 | name / command / description | Обязательное поле |
| Не 3 примера | 400 | examples | Нужно ровно 3 примера |
| Меньше 5 тегов | 400 | tags | Минимум 5 тегов |
| Изменить свою роль | 409 | role | Нельзя изменить роль своей учётной записи |
| Удалить себя | 409 | — | Нельзя удалить свою учётную запись |
| Понизить или удалить последнего админа | 409 | role / — | Должен остаться хотя бы один администратор |
| Команда или пользователь уже удалены | 404 | — | Команда не найдена / Пользователь не найден |
| Любая другая ошибка сохранения | 500 | — | Ошибка сервера. Попробуйте ещё раз |
