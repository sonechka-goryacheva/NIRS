# НИРС: справочник IT-команд с RAG

«Справочник IT-команд» помогает подобрать консольную команду по описанию задачи обычными словами
(«не хватает прав при запуске скрипта», «что делает du -sh») или объяснить уже известную команду.
Ответ строится по собственному датасету команд: поиск BM25 находит кандидатов, LLM оформляет ответ —
название, команда, описание и 3 примера применения. Веб-чат требует входа, поддерживает роли user и admin;
личные чаты сохраняются до удаления с подтверждением.

В репозитории есть локальный фронтенд на HTTP-моках (макет интерфейса для КТ1): он работает без сервера,
аккаунты и ответы в нём учебные. Поиск BM25, корпус и benchmark — в `app/`, `data/`, `benchmark/`.
Сервер FastAPI, который свяжет интерфейс с настоящими авторизацией, поиском и LLM, ещё не реализован.

> Фронтенд находится в ветке `feature/web-frontend` (pull request в `main`). После слияния — в папке `web/`.

## Запуск фронтенда

Нужен только Python 3.10+ (без Node.js и установки пакетов). Из корня репозитория:

    python3 web/serve.py

Открыть http://localhost:8080. Сервер `serve.py` отдаёт файлы без кэша и пишет запросы в терминал.
Если порт занят, он сообщит об этом и запустится на следующем свободном.

Основные страницы: вход, регистрация, чат с историей, датасет команд, профиль;
для роли admin — редактирование датасета и управление пользователями. Все адреса — в `spec/tech/ui_tech.md`.

## Учебные логины и пароли

Работают только в режиме моков. Регистрация создаёт пользователя; администратора создаёт действующий admin.

| Роль | Логин | Пароль |
|---|---|---|
| Пользователь | `demo` | `demo123` |
| Пользователь | `ivan.petrov` | `qwerty12` |
| Администратор | `admin` | `admin123` |

## Моки и интеграция

Экраны обращаются к серверу только через `web/assets/js/api/` (обычный `fetch`, сессия в cookie).
Мок подменяет `fetch` для `/api/*` и отвечает как сервер: те же пути, коды, `{detail, field}`.
Переход на сервер: в `web/assets/js/config.js` поставить `useMock: false` и удалить папку `web/assets/js/mock/` —
остальной код не меняется. Подробно — `spec/tech/ui_tech.md`, контракт — `spec/tech/api.md`.

## Дизайн

Мятная палитра со «стеклянными» плашками: тёмная изумрудная тема для входа и регистрации, светлая мятная — для приложения.
Иллюстрация входа — изометрические клавиши `>_`, `Ctrl`, `C`, `Tab`; логотип — две плашки со строками текста.
Шрифты Inter и JetBrains Mono. Все цвета — токены в `web/assets/css/theme.css`. Описание — `spec/product/design.md`.

## Проверки

    pip install -r requirements.txt
    pytest tests/
    python benchmark/run.py

Фронтенд проверяется вручную по сценариям `spec/product/scenarios.md` под ролями гость, user, admin
(на ширине компьютера и телефона). Показ макета на моках не подтверждает готовность сервера, качество поиска или ответы LLM.
