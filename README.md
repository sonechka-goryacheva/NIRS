# NIRS
# Справочник IT-команд

Приложение, которое по запросу на естественном языке находит нужную команду
и объясняет её применение. Работает через BM25 + LLM.

## Возможности
- Чат с нейросетью.
- Поиск по датасету команд.
- Просмотр команд по категориям.
- История чатов.
- Роли: пользователь и администратор.

## Запуск
pip install -r requirements.txt
python -m app

## Основной сценарий
Пользователь пишет: «как посмотреть размер папки»
→ Приложение находит du -sh
→ Показывает команду, описание и 3 примера.
